# Práctica HTML y CSS — Portfolio con Flexbox

Portfolio profesional responsivo maquetado con **HTML5 semántico** y **CSS Flexbox**. Práctica de la 2ª evaluación de *Lenguajes de Marcas* (1º de ASIR, Liceo La Paz).

## Qué cumple

- **HTML semántico**: `header`, `main`, `section`, `article`, `figure`, `nav` y `footer`, sin `div` envolventes innecesarios.
- **Flexbox** para toda la disposición, con `flex-wrap` para que se adapte a cualquier ancho de pantalla.
- **Variables CSS** (`:root`) para la paleta de colores, las sombras y las transiciones.
- **Hover** en etiquetas, botones, tarjetas y enlaces (cambio de color, escala o desplazamiento).
- Cada regla CSS lleva un **comentario** que explica su cometido.

## Estructura

```
FlexboxRocaDaniel/
├── index.html      página del portfolio
├── css/css.css     hoja de estilos
└── img/            foto de perfil
```

## Verlo

Abrir `index.html` en el navegador; no necesita servidor ni dependencias.
